# Thynk website — prototype v5 (reference only)

Standalone HTML prototype of the approved v5 interface (fixed viewport, dark-first, pinned Muse, views About / Solutions / Method / Calculator / Contact).
Open `index.html` locally to preview. This folder is a **design reference** for the real site in `src/` — it is not served by the app.

- `index.html` — prototype (single file, inline CSS/JS)
- `wordmark-light.png` — light wordmark for dark backgrounds
- `muse-hero.jpg`, `muse-ipad.jpg`, `muse-thoughts.jpg` — Muse poses used per view (720px, optimized)
