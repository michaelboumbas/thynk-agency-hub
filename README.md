# Thynk Agency Hub

Το project λέγεται "Thynk Digital Agency — Website". Είναι το επίσημο website της ίδιας της Thynk (digital agency, Ιωάννινα), one-page hero site.

ΣΗΜΑΝΤΙΚΟ: ΜΗΝ γράψεις και ΜΗΝ αλλάξεις κανέναν κώδικα ακόμα, μην δημιουργήσεις σελίδες ή components. Πρώτα θα συνδεθεί το project με GitHub (τα κείμενα/εικόνες περνάνε απευθείας μέσω GitHub commits, όχι μέσω agent, για εξοικονόμηση credits). Μόλις συνδεθεί το GitHub, θα λάβεις αναλυτικό prompt βάσης με το design system, τα routes/sections και το πραγματικό copy. Μέχρι τότε, μείνε στον προεπιλεγμένο σκελετό και απλώς επιβεβαίωσε ότι το κατάλαβες.
